# Presence账号

在「设置 → 插件 → Presence → Presence账号」选择创建账号或登录，使用该Presence服务的邮箱和密码。当前NAS账号网页为[GitPresence账号](https://git.freshli4.com:10443/presence/account)，注册界面是否开放由实际服务配置决定。0.28.0客户端源码包含应用内入口；源码更新不等于安装版更新。

个人Docker实例只允许创建一个账号，首次创建需安装者提供的安装密钥；后续设备直接登录，不需要安装密钥或设备登记密钥。账号可绑定多个仓库，包括你有权访问的GitHub/Gitea组织仓库；个人Docker不提供Presence组织空间、成员/角色管理或跨账号控制。

登录后，在“绑定的仓库”选择当前Git账号有权访问的仓库；其他电脑登录相同Presence账号后共享绑定。再在“远端控制”登记此设备，并明确开放目标电脑的本机项目，即可从项目页要求另一台设备Commit、Submit或两类abort。绑定不上传文件内容，Git凭证继续留在各台设备。

“重新登录”更换会话但保持同账号设备关联；切换账号或服务器不会展示之前的设备和结果。“退出此设备”停止接收并撤销本设备凭证；修改密码撤销所有会话与旧设备授权，需要各设备重新登录和登记。已观察的编辑器状态仍由独立本机Bridge读取，新账号不会自动继承旧Bridge/只读用户的身份或权限；应用仅在绑定范围内转发本机已观察状态。

首版邮箱作为登录名，尚未验证邮箱，也暂不提供邮件找回。GitHub/Gitea仓库登录与Presence账号分别授权；GitHub/Gitea直接登录Presence及跨平台身份绑定尚未实现。

独立账号、组织邀请/管理、计费和正式三平台发布属于不同交付项。本轮实现账号入口与授权边界，未把正式付费服务、官网Docker下载或实际用户双设备验收标记为完成。
