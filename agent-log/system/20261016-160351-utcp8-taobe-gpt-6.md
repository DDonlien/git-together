## 本轮修改

- GitHub 账号按账号共享读写锁。Git 获取凭据前按最大操作时间加一分钟余量检查续期；领取凭据后持有读锁到 Git 及其输出管道结束，续期交换持有写锁。不同仓库使用同一账号时也共享保护，系统认证不走应用令牌锁。保留原授权代次、加密保存与取消后的轮换完成机制。
- 解析 stdout 与 stderr 的有限错误特征，区分工作流权限、SSO、仓库写权限、凭据缺失/拒绝、SSH 密钥/主机、远端规则/接收钩子、仓库不可见、限流及 non-fast-forward；不再从通用推送失败猜测远端领先。
- 后台 Git 日志记录 authentication=system/account 与白名单 gitFailureReason，拒绝 renderer 注入；不记录原始输出、令牌、目录、仓库 URL 或账户名。同步前端公共错误分类。
- 版本 patch 从 0.34.0 更新至 0.34.1，修复既有认证生命周期和错误诊断，不引入新账号/远端配置格式。
