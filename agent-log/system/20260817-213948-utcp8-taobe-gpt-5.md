## 任务范围与需求归属

- 新增 `F-0.1.10 Subscription and API AI providers`。
- AI Options 将 ChatGPT 订阅、OpenAI API key 与 OpenCode Go API key 表达为三个独立 Provider。
- 现有 `openai` 配置 ID、API key、模型和 endpoint 保持兼容，只把界面名称改为 OpenAI API。
- ChatGPT 订阅使用系统浏览器进行 OAuth 2.0 PKCE 授权；不抓取浏览器 Cookie，也不读取 ChatGPT、Codex 或其他应用的私有凭据文件。
- OpenCode Go 使用用户自行取得的 API key，并按模型族路由到 Responses、Chat Completions 或 Anthropic Messages 兼容协议。

## 参考与架构决策

- 参考 OpenAI 的 ChatGPT 登录授权文档，明确区分 ChatGPT 订阅授权和按量计费 API key。
- 参考 Zed `openai_subscribed` 的公开实现，采用浏览器 OAuth、PKCE、localhost callback、refresh token 和 ChatGPT account header 的总体模式，而不是复制或抓取其他应用的本机凭据。
- 参考 OpenCode Go 官方模型与协议说明，动态读取模型目录并按协议家族构造请求。
- Rust/Tauri 独占 token、API key、刷新、模型发现和 provider HTTP 请求；Svelte 只接收登录/密钥状态、非敏感账号展示信息、模型列表和流式文本。
- 新增 secret 只写 macOS Keychain；IPC 错误日志对新增请求和既有 secret 请求的参数做脱敏。
