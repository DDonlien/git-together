# Dashboard 七项 Git 操作定义

- 用户原始 prompt：
  > 右侧的交互按钮这几个：
  > commit, fetch, pull, push；这就是常规的
  > get latest：从 perforce 学来的语义，本质上是一个 1 层（最新版本）的浅拷贝，并且会拷贝完把超过 1 层的删掉来释放空间，核心目的是省空间，尽管本质上 LFS 是只保存指针版本了，但 diff 多了还是很大的，而且本质上没有必要保存多个，又不是真的邮件时代
  > reconcile：从 perforce 学来的语义，把本地的和远端检查，本地多于远端的标记为添加，本地于远端不同的提交（本地为准），本地少于远端的忽略
  > clear：从 perforce 学来的语义，把本地的和远端检查，本地多于远端的标记为删除，本地于远端不同的修改（远端为准），本地少于远端的下载
- 模型：GPT-6。运行环境仅暴露此标识，没有可确认的更细版本。
