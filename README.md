# GitTogether

一个从零实现的 TypeScript 多仓库工作台。当前版本 0.8.7 从账号导入开始：设置连接账号，侧栏立即显示该账号的全部可访问仓库，Dashboard 在统一列表中展示仓库名称、所属组织或用户、访问账号和本地目录。点击仓库的文件夹图标即可独立展开或收起实际远端分支，一行一个分支，不要求先关联本地；点击仓库名称仍打开工作区。需要查看本地更改时，再关联已有 Git 目录。GitHub 默认网页授权，访问令牌作为折叠的备用方式；Gitea 继续使用指定域名与访问令牌。

已按用户反馈恢复试用前的 OpenGlass 界面：悬浮侧栏、统计分组、独立搜索筛选行和统一仓库表。Ring UI 试用已撤回，原有功能保留；本次没有重新生成或替换桌面安装包。

文件树的分支名和短提交哈希同一行右对齐；长分支名末尾渐隐、不换行，完整名称仍可悬停查看。本地目录身份与原树状态保留。

侧栏开关、Dashboard 与设置采用32×32细描边圆角方形图标槽，收起时不放大；收起后是56px图标栏，仓库与账号展开按钮也具有32×32圆角方形点击区域，仓库仅保留居中的文件夹图标与状态点。非固定入口默认无描线，选中仓库才出现整块细描线。展开后的仓库图标与名称不再额外缩进，与账号行同列对齐，保留整行点击区域；原有配色、提示、键盘操作及账号会话保持。仓库工作区文件树的真实目录层级缩进不受影响。

0.8.0 文件行右侧在悬停或键盘聚焦时显示独立打开按钮：远端打开当前分支文件树基准的 GitHub/Gitea 文件网页，本地用系统默认应用打开已关联工作目录里的实际文件。打开不改变提交、文件选择或草稿；当前目录不存在的历史条目不能打开。系统打开的仓库/任务/字面路径由服务校验，不接受任意 URL、目录或命令。代码、隔离生产页面与实际 macOS 默认应用已验证；旧桌面安装包未更新，真实账号私有文件网页验收单列。

0.6.0 的分支图参考 [GitLens Commit Graph](https://help.gitkraken.com/gitlens/gl-commit-graph/)：连续彩色轨道、分支标签、紧凑行，以及整行选择、键盘导航、搜索跳转和只读菜单。以自有 TypeScript/SVG 绘制真实父子关系，保留中栏历史详情、独立三栏开关与草稿；搜索仅覆盖已读取提交，不执行 Git 写操作。交互与视觉细节见 [设计规范](DESIGN.md#布局)。

分支图和文件树不显示底部状态/操作栏，也没有「分支图选项」菜单；保留分支下拉、键盘搜索跳转与提交右键操作。三栏标题和内容统一12px左右留白，树层级缩进不变。本地目录配置从 Dashboard 访问，内容直接使用释放的高度，不保留空白占位。

分支图左侧标题显示当前查看的分支名，点击名称直接下拉选择，不再有独立「定位分支」按钮。选择更新标题并定位已读取分支头，不检出分支或修改 Git；独立收起和任务草稿保持。

这是独立的 `codex/standalone-ts` 分支，与原 GitButler fork 没有共同历史。支持 GitHub、指定域名的 Gitea 和同一 host 的多个账号。账号按令牌权限读取仓库；每个账号下的仓库与本地关联状态无关，未关联目录也能打开查看远端信息。本地目录通过弹窗验证远端是否匹配。

设置中的账号行保留「编辑」，「移除」位于编辑弹窗左下角，二次确认后只删除应用内记录，不删除本地文件。取消移除保留编辑草稿。编辑可修改账号名称，或填写同一身份的新访问令牌；令牌留空保留原凭据，不回显现有令牌。平台、域名和用户名固定，换身份需添加账号。验证或保存失败不覆盖原连接与输入，成功后侧栏和 Dashboard 账号列同步更新。

Dashboard 的行尾菜单分为 Git 与 GitTogether，可打开工作台或配置本地目录。尚未接入的 Fetch、Pull、Push 和提交明确禁用，不模拟成功；点击本地目录栏的「尚未关联」或已有路径文字即可打开配置弹窗。

中栏一次显示一个上下文：选择提交后列出该次提交的全部差异文件，标题菜单可切换平铺列表或 Added / Modified / Deleted 分组，说明固定在底部，只有文件列表内部滚动，不再按分支叠成长页或裁切为160px。历史说明用摘要标题和只读正文显示，不呈现输入框或提交状态；当前运行服务仍只提供摘要，完整正文接入另见[需求记录](REQUIREMENTS.md)。未选提交时展示当前本地目录的真实未提交更改；没有本地目录时等待明确选择，不默认读取/显示远端 HEAD 差异。多个本地任务可通过中栏菜单切换，隐藏卡片仍挂载以保留各自草稿。取消选择恢复本地提交区和草稿，或远端空状态；远端不显示禁用 composer，不恢复已移除的内嵌内容预览。顶部「显示全部任务」、三栏独立开关、完整文件树和本地更改身份保留。

文件树固定为当前分支 HEAD 或本地工作目录的完整目录，历史选择不替换目录和基准 SHA。参考 [Zed 项目面板](https://zed.dev/docs/project-panel#git-integration)，选中提交只叠加绿色新增、黄色修改/重命名、红色删除，文件与父目录均有颜色和状态字母；已不在当前目录的差异路径以明确的历史条目保留。取消选择清除远端差异标记，目录展开与草稿保持；本地树仍展示真实工作目录状态，不冒充尚未接入的本地历史 Diff，本地历史选中时明确提示未接入。

仓库页已按最新标注移除重复顶栏，基础信息合并为横贯分组：仓库名下显示完整远端地址，只保留访问账号和默认分支，不重复显示账号身份细节或本地路径；目录关联和配置入口位于文件树的本地来源中。下方固定为「分支图 / 更改与 Diff、底部提交说明 / 文件树」三栏，各栏标题有独立收起/展开按钮；收起保留44px窄栏并让其他栏扩宽，不清空选择、草稿或目录状态。多个 branch/worktree 按任务卡片同时展示；聚焦仅过滤视图，不切换 checkout，并保留每个任务的草稿、文件选择和目录展开。文件树标题右侧可切换「远端 / 本地」，只改变该栏来源，不影响分支图或 Diff；未关联本地显示明确空状态。窄窗口在工作区内部横向滚动，不用页签隐藏列。

0.5.0 已把远端内容读取器正式接入 AccountService、有限 API/HTTP/IPC 与生产 App：选中仓库即读取 GitHub/Gitea 的真实分支、提交父子关系、分支文件树和已提交文件列表，不要求本地目录。多个分支同时显示，选择历史提交时文件列表与树上的差异标记对应同一提交，树本身保持当前分支完整目录；按最新标注，远端列表下方的内嵌文本预览已移除，本地未提交 Diff 保留。Commit 仍禁用，不克隆或执行 Git 写操作。两个 provider 的服务→HTTP→客户端完整链路及生产 App 已通过独立真实临时 Git 验证；直接只读访问用户 Gitea 1.26.2 的公开 backrooms 仓库也读到 3 分支、16 提交和完整树/Diff，但这不等于登录后的页面验收。用户明确批准此前的 4173 服务接入更新，网页账号需重新连接；本次移除预览不重启服务，也不更新旧桌面包。

搜索位于仓库表上方筛选行的最左侧；账号使用轻量菜单，组织按访问账号分组多选，仓库按远端/本地及 Original/Fork/Added 两组多选。全选不限制、空选无结果，没有额外「全部」选项；个人和未确认归属分别可选，未知分类不猜测。前台自动检查远端仓库目录及打开仓库的分支 HEAD（约 60 秒）、已关联本地目录和选中 Diff（约 5 秒）；恢复窗口/网络后检查，失败退避并保留上次数据与搜索/选择。它不是远端提交推送或自动 Git fetch，不会修改用户仓库。

本地配置弹窗已去掉两段常驻说明，目录栏改为「选择文件夹」入口，桌面复用系统文件夹选择器；选好后仍需保存并验证仓库远端。取消选择保留原目录，不把浏览器上传的文件名当成本地路径。当前浏览器预览的系统选择器接口仍待接入和原生验收；本轮获许可的账号编辑服务更新没有包含该接口。

GitTogether 自有 GitHub App 已注册。本机浏览器的正常网页授权已接入独立回调服务：点击按钮打开 GitHub 登录/同意，服务端交换授权码后导入账号，应用自动更新；不再要求输入设备验证码。开发者通过单独的本机配置页输入应用密钥，普通用户不注册应用，也不配置 Client ID、密钥或回调。密钥不进入前端、源码或安装包；已修正客户端 CSP 漏放行本机 API 和辅助服务系统网络问题。用户于 2026-10-07 完成真实网页确认，本机回调后 GitHub 账号与 38 个仓库目录已读回，原 Gitea 会话及20仓库保留。可访问范围仍受应用权限/安装范围限制，不据此保证全部私有和组织仓库。已暴露密钥的轮换尚未确认完成。开发配置见 [运行说明](docs/development.md#github-正常网页授权本机开发)。原生桌面的正常浏览器返回与生产授权服务仍未接入；原设备授权代码保留。账号服务断连可重新连接，版本不一致时明确提示刷新，不自动重试凭据提交。

2026-10-07 已修复授权辅助服务的系统网络接入和等待黑屏：独立 Electron 进程自动使用系统代理/PAC/直连，回调立即显示进度，错误不再等请求结束前一直空白。受控运行时网络回归和实际本机网页授权已分别验证。只重启了辅助服务，主服务和原 Gitea 账号保留；用户在 [本机配置页](http://127.0.0.1:4174/setup) 自行重新输入应用密钥，configured=true。授权返回后目录共 58 个仓库。桌面账号网络源码已同步，未更新安装包；保留的 4173 Node 仓库服务仍使用原网络路径，其他网络环境的整条导入尚未实测，仓库内容接口接入仍是独立待办。

2026-10-07 本机授权助手已改为系统加密持久保存应用配置，重启自动恢复；新授权绑定当时的主服务，旧回调仍不能跨重启导入。仅更新了4174，主服务实例保持不变。旧内存密钥不能安全自动迁移，首次升级需开发者在本机配置页直接输入一次；当前等待本人保存，不表示真实密钥已恢复。跨进程系统加密及新旧授权隔离回归已通过，安装包与生产授权未更新。

桌面版使用系统安全存储加密保存账号与令牌；本地浏览器预览的账号只保存在服务会话里，重启服务后需要重新连接。这与上述应用开发配置的加密持久保存是不同数据。localStorage 只保存外观与账号折叠偏好，不保存令牌。账号初始为空，没有内置场景/模拟数据。已有本地仓库可以只读查看真实更改、Diff 与最近历史，不自动克隆，不执行暂存、提交、拉取或推送；AI、Agent 与 Presence 在线连接尚未实现。

已提供独立的 macOS Apple Silicon 本地打包入口，`.app` 内置页面和账号服务，不依赖网页预览。原生玻璃与系统目录选择器的打开、取消、目录返回已实测；桌面账号仍需独立连接，不复制网页令牌。构建命令、签名范围和产物位置见 [本地包说明](docs/development.md#独立-macos-本地包)。

界面参照用户提供的 Wireframes v0.1 和系统设置截图：共享窗口背景、四周内缩的悬浮导航、无阴影的平面内容分组。红绿灯位于窗口顶端；侧栏收起按钮在 GitTogether 名称旁，收起后保留56px图标列，品牌由展开按钮替代，导航仍可操作，当前页面与任务状态保留。横向、纵向滚动条隐藏，仍支持滚轮、触控板和键盘滚动。采用系统字体与统一 OpenGlass UI 控件；Electron 在受支持的 macOS 上使用原生玻璃背景，React 控件本身不是 AppKit 原生控件。

开发入口会共同检查页面、账号服务和授权助手，已有的系统加密应用配置自动恢复；无需每次重新注册 GitHub App、填写密钥或回调。普通用户只进行自己的 GitHub 登录/同意，浏览器账号会话与应用开发配置分开。回调返回完整页面并单独查询结果，不依赖长响应绘制进度；当前完整真实授权验收仍以用户完成导入为准，配置恢复不等于账号已连接。

0.7.2 回调页显示轻量等待动画、实际处理阶段、已等待时间和最近状态更新时间。单个阶段等待15秒后提示耗时较长，不用计时假装推进或显示百分比；成功、明确失败或状态读取中断会停止动画，并分别表达完成、失败或结果尚未确认。支持亮暗色和减少动态效果。
